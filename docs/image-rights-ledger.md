# 생성 이미지 권리 장부

생성 이미지는 입구 분위기만 담당하며, 과학 도식(주사기 단면·피스톤·공기 표식)은 프로그램 SVG로 제공한다.
모든 자산은 로컬 파일로 동일 출처에서 제공하며 외부 핫링크를 사용하지 않는다.

## 검수 규칙

- [ ] 각 이미지에 문자·정답·색상만으로 전달되는 정보가 없다.
- [ ] 실제 기기 조작 단계, 압력 수치, 신체 안전 관련 표현이 없다.
- [ ] 권리 장부 항목과 로컬 파일이 1:1로 대응한다 (`tests/release/pages-assets.test.ts`가 검사).
