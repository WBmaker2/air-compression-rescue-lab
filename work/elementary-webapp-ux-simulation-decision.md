# 시뮬레이션 개선 판단

- 판단일: 2026-08-31
- 결정: `not-needed` — 이번 후속 개선에서는 새 시뮬레이터를 추가하지 않음

## 근거

현재 앱의 학습 목표는 실제 압력 계산이나 연속적인 물리 실험이 아니라, 고정된 관찰 기록에서 다음 관계를 읽는 것입니다.

1. 밀폐: 같은 표식이 더 작은 공간에 모임
2. 열림: 일부 표식이 출구로 나감
3. 누출: 관찰마다 표식 수가 줄어듦
4. 정보 부족: 결과를 꾸며 내지 않고 판단 보류

이 목표에는 현재의 결정적 DOM/SVG 모형, 전후 비교 표, 관찰 근거 선택, 뒤로 가기, 처음부터 다시 하기가 충분합니다. 자유 슬라이더·랜덤 값·시간 흐름·Canvas/WebGL을 추가하면 모형의 질적 규칙보다 조작 자체가 앞설 위험이 있습니다.

## 현재 모델의 경계

- `missions.ts`의 고정 fixture가 유일한 관찰 사실입니다.
- `airModel.ts`는 정해진 전이와 관찰 키를 평가합니다.
- SVG는 모형 값과 시각적 관계를 표시하며 실제 측정 도구가 아닙니다.
- 미션 5는 결과가 제공되지 않는 상태를 표현하고, 미션 6은 세 관찰 기록의 signature를 진단합니다.
- 정답을 물리 엔진으로 계산하거나 외부 자료로 보강하지 않습니다.

## 새 시뮬레이션이 필요해지는 조건

향후 학습 목표가 `부피를 연속적으로 바꿀 때 표식 간격과 저항 변화를 스스로 탐구하기`로 명시적으로 바뀌는 경우에만 별도 시뮬레이션을 검토합니다. 그때도 다음 계약을 지켜야 합니다.

- 모든 조작에 reset/restart와 현재 단계 표시가 있어야 함
- 실행 전후 값과 변화 근거를 같은 화면에서 비교할 수 있어야 함
- 0/1/여러 전이의 결과가 고정 fixture와 테스트로 재현되어야 함
- reduced motion에서도 시간 애니메이션 없이 동일한 관찰 결과를 확인할 수 있어야 함
- 실제 주사기 조작 지시나 안전하지 않은 행동 유도로 읽히지 않아야 함

이번 작업은 이 경계를 건드리지 않고, 잘못 연결된 관찰 키와 학생용 문구만 바로잡습니다.
