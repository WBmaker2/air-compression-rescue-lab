## 생성·교체 규칙

- 일반 장식·개념 자산만 `$imagegen` 후보가 될 수 있습니다.
- 생성 시 원본을 덮어쓰지 않고 `safe-virtual-air-lab-v2.webp`처럼 의미가 드러나는 버전 파일을 사용합니다.
- 생성 프롬프트에는 초등 5~6학년, 입구 분위기라는 화면 역할, 밝은 라이트 모드, 필요한 비율, 문자·수치·로고·실제 장치 조작 지시 금지를 명시합니다.
- 과학 도식·측정값·지도·차트·스크린샷·로고·실제 인물/장소는 자동 생성·교체하지 않습니다.
- import, JSX/HTML, CSS `url`, preload, srcset, 테스트 fixture를 모두 검색하고 빌드에서 로드되는 것을 확인합니다.
- 자산별 출처·프롬프트·생성일·화면·alt·검토 상태는 이 문서와 기존 `docs/image-rights-ledger.md`에 함께 남깁니다.
